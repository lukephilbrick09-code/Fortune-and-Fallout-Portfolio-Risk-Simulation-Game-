# 🎲 Fortune & Fallout

 A Python Portfolio Risk Simulation Game

**Fortune & Fallout** is a Python-based financial simulation game where players build and manage an investment portfolio and attempt to grow their wealth while surviving changing market conditions.

The project combines **Python programming with financial concepts** including portfolio allocation, asset returns, risk, volatility and compound growth.

> **Can your portfolio survive the market?**

---

🎯 Project Objective

The aim of Fortune & Fallout is to create an interactive investment simulation where players must make financial decisions while balancing **risk and reward**.

The project is being developed progressively, starting with a simple portfolio simulation and eventually developing into a more complete financial game.
